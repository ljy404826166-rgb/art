## 上线前必须完成

以下事项不是文案可以替代的合规义务。未完成前，不应把本套文本标记为“正式生效”：

1. 将所有 `【待填写】` 项替换为真实、持续有效的信息，包括运营者法定名称、统一社会信用代码或个人主体身份说明、注册地址或经常居所、联系邮箱、客服电话、投诉渠道、协议生效日期。
2. 确认小程序备案、经营范围以及依法可能需要的许可与实际服务一致；如新增付费、广告、交易、评论、用户发布、个性化推荐或面向儿童的功能，应另行评估并修订文本。
3. 在用户首次创建账号或启用云同步前，以显著方式展示《用户协议》和完整《隐私保护指引》，对免除或限制责任、服务终止、账号处置、争议解决等重要条款进行加粗或其他显著提示，并保留版本号、同意时间和可核验记录。当前代码在用户进入“我的”等页面时会调用 `getOrCreateProfile` 自动创建云端账号，且 `privacy_version` 初始为空；正式上线前应改为先展示规则并取得有效确认，再创建账号、登记规则版本和启动云同步。
4. 微信公众平台中的《用户隐私保护指引》必须逐项、真实披露头像、昵称、微信身份标识、收藏、关注、浏览历史、成就、下载数量摘要、设备端存储、云端存储、第三方处理者、保存期限和用户权利路径。不能仅以当前小程序内的简版说明代替。
5. 现有注销逻辑会删除头像文件及用户收藏、关注、浏览历史、成就等业务数据，但会保留带微信身份标识的注销状态记录及删除时间。应确定该保留的具体目的、法律依据、最短期限、访问权限和到期删除规则，并在隐私保护指引中披露；不得表述为“全部个人信息立即彻底删除”。
6. 对用户昵称和头像建立上线前审核、投诉、处置和复核机制。仅依赖客户端字符校验不足以处理冒用身份、侵害肖像权、违法或不良信息等风险。
7. 每件上线作品应具有可追溯的来源页、权利状态、许可名称、许可链接、署名要求及人工复核记录。来源平台标注“Public Domain”只能作为证据之一，不能替代对原作、数字化图像和来源机构条款的核验。
8. 下载按钮只应向权利状态和下载条件已经复核的作品开放；下载页及详情页应明确提示“提供下载技术能力不代表授予商业使用或其他再利用许可”。
9. 建立并实际运行权利通知处理流程，包括收件登记、身份与证据核验、必要的临时处置、转送或申辩、结论反馈、记录保存以及恶意通知处理。
10. 确认 `MasterpieceArt@163.com`、联系电话和小程序客服等对外联系方式真实可用并由本人或指定人员持续处理；联系方式发生变化时，应及时更新全部公开文本和备案信息。
11. 核查微信云开发、对象存储、内容分发网络、客服会话等受托处理或第三方服务，签署必要的数据处理条款，限制用途和权限，并完成安全措施、数据事件预案及供应商清单。
12. 对小程序内所有艺术家肖像单独核验肖像来源、著作权许可和署名要求；作品原作进入公有领域，不当然意味着其数字化照片、人物肖像或页面文字也可自由使用。
