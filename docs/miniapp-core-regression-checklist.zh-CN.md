- [ ] `npm run check`

- [ ] `npm run build`
- [ ] `git diff --check`

## 微信开发者工具 / 真机检查

### 首页

- [ ] 首页打开后只显示顶部导航栏中的唯一标题“画廊”，没有重复标题。
- [ ] 搜索输入框停留在首页内，不再跳转到独立搜索页。
- [ ] 输入搜索词时，搜索结果能边输入边更新。
- [ ] 清空搜索词后，页面恢复原本首页分区内容。
- [ ] 横向作品栏可以左右拖动。
- [ ] 横向作品卡片保持“图片高度固定、宽度按图片比例变化”的展示逻辑。
- [ ] 作品卡片标题和作者过长时单行省略，不折行、不溢出卡片。
- [ ] 每个分区的“查看更多”能进入对应标签/分类的完整作品页。
- [ ] 下拉或触底加载更多时，新内容追加在已有内容后，不替换已有内容。

### 分类页

- [ ] 流派、题材、媒介等筛选标签可以正常选中和取消。
- [ ] 选中标签后，结果数量与当前筛选条件一致。
- [ ] 作品结果使用双列网格展示。
- [ ] 作品卡片有圆角和阴影，不与背景融在一起。
- [ ] 作品标题和作者都保持单行省略。
- [ ] 触底后如果还有更多作品，会继续加载并追加到当前列表底部。
- [ ] 点击作品卡片后进入对应作品详情页。

### 标签完整作品页

- [ ] 页面标题和当前标签名显示正确。
- [ ] 作品数量显示正确。
- [ ] 作品结果使用双列网格展示。
- [ ] 触底后继续加载更多作品，并保留当前已加载内容。
- [ ] 点击作品卡片后进入对应作品详情页。

### 作品详情页

- [ ] 详情主图使用 `display_url` 展示，不默认请求 `download_url` 原图。
- [ ] 进入详情页时，图片加载骨架屏尺寸与最终主图区域基本一致。
- [ ] 收藏按钮可正常切换状态，且不会造成布局跳动。
- [ ] 下载按钮位于收藏按钮旁边。
- [ ] 点击下载后使用 `download_url` 保存图片，并记录下载历史。
- [ ] 点击作者黑色胶囊按钮后，直接进入对应画家详情页，不出现阻塞式“读取中”弹窗。
- [ ] 点击底部标签后，进入对应标签完整作品页。

### 画家页

- [ ] 画家列表读取微信云数据库数据，不使用本地 8 位画家 fallback。
- [ ] 搜索画家名称、地区、流派、年代时能正确筛选。
- [ ] 地区、流派、年代筛选标签可以正常切换。
- [ ] 初始加载显示一批画家卡片。
- [ ] 触底后每次追加 8 位画家，不替换已有画家卡片。
- [ ] 触底加载后浏览位置保持稳定。
- [ ] 点击画家卡片后进入对应画家详情页。

### 画家详情页

- [ ] 页面骨架屏结构与最终画家详情页结构一致。
- [ ] 画家头像、姓名、英文名、简介、国籍、流派、活跃时期、代表作品等信息来自云数据库。
- [ ] 画家基本信息先渲染，不需要等待相关作品全部加载完成。
- [ ] 相关作品初始加载 8 张。
- [ ] 触底后继续追加 8 张相关作品。
- [ ] 相关作品追加后，已有作品和滚动位置不被重置。
- [ ] 相关作品卡片点击后进入对应作品详情页。

### 我的页 / 下载管理

- [ ] 我的页可以正常打开。
- [ ] 下载管理入口可以进入下载记录页面。
- [ ] 已下载作品记录展示正确。
- [ ] 清空下载记录后页面状态更新正确。
- [ ] 没有下载记录时显示空状态。

## P0 微信原生能力

### 作品预览

- [ ] 点击作品详情主图后进入微信全屏图片预览。
- [ ] 预览请求使用 `display_url`，不提前请求 `download_url` 原图。
- [ ] 没有可预览图片或基础库不支持时显示明确提示。

### 分享

- [ ] 作品详情分享卡片标题、图片和作品 ID 正确。
- [ ] 画家详情分享卡片标题和画家 ID 正确。
- [ ] 从分享卡片冷启动后直达对应详情页。
- [ ] 分享目标不存在时展示可恢复错误状态。

### 网络与原图下载

- [ ] 断网时详情页保留已加载内容并显示网络提示。
- [ ] 断网点击下载不会调用 `wx.downloadFile`。
- [ ] 使用移动网络下载原图前显示流量确认。
- [ ] 用户取消移动网络下载后不产生下载记录。
- [ ] Wi-Fi 下载继续沿用当前相册权限和失败恢复流程。
- [ ] 网络恢复后用户可以主动重试加载或下载。

### 兼容性

- [ ] API 不可用时功能降级，不出现白屏或无限加载。
- [ ] Android 微信真机完成预览、分享、断网和移动网络检查。
- [ ] iOS 微信真机完成预览、分享、断网和移动网络检查。

## 图片与流量检查

- [ ] 首页、分类页、标签页、画家详情相关作品列表默认使用 `thumbnail_url`。
- [ ] 作品详情页默认使用 `display_url`。
- [ ] 只有点击下载时才使用 `download_url`。
- [ ] 普通浏览过程中 Network 中不应提前请求原图下载链接。
- [ ] 图片加载失败时显示 fallback，不出现空白卡片。

## 状态检查

- [ ] 加载中状态不遮挡主要内容。
- [ ] 空状态文案清晰，能说明当前没有结果。
- [ ] 错误状态显示可理解的错误信息，并提供重试入口。
- [ ] 弱网或云数据库读取失败时，不静默回退到错误的本地数据。
