# Masterpiece 小程序账号中心中文回归清单

**版本：** v1  
**适用范围：** 微信原生小程序 `miniapp/`  
**执行顺序：** 体验环境验证 → 生产环境预览 → 正式版本发布  

## 1. 验收准备

- [ ] 微信公众平台已发布头像、昵称相关的用户隐私保护指引。
- [ ] 微信公众平台已绑定至少一名小程序客服人员。
- [ ] 准备微信测试账号 A、测试账号 B；两者不得使用正式运营账号。
- [ ] 准备 iOS、Android 各一台真机，另有 iPad 时增加同账号跨设备测试。
- [ ] 确认体验和生产环境的 `accountProfile` 云函数均为 `Active`。
- [ ] 确认 `users`、`user_favorites`、`user_followed_artists`、`user_history` 均为 `ADMINONLY`。

## 2. 公共浏览与异常隔离

- [ ] 首次打开首页能够显示内容，不要求头像、昵称授权。
- [ ] 首页、分类、画家和作品详情在账号云函数失败时仍可浏览。
- [ ] 断网进入“我的”页时，本机统计立即显示，并出现可理解的离线提示。
- [ ] 错误提示不包含 `_openid`、数据库路径、云函数内部路径或原始异常堆栈。

## 3. “我的”页与个人资料

- [ ] 首次进入“我的”页无空白，无长时间无反馈。
- [ ] 收藏、关注和历史数量先从本机显示，账号状态随后异步更新。
- [ ] 连续切换 Tab 不会出现无限请求、计数反复跳变或页面闪烁。
- [ ] “偏好设置”入口不存在。
- [ ] “关于 Masterpiece”品牌名称正确，不再出现 `Art Archive`。
- [ ] iOS 能够选择头像、填写昵称并保存。
- [ ] Android 能够选择头像、填写昵称并保存。
- [ ] 非法昵称被拒绝，旧头像和旧昵称仍保留。
- [ ] 连续点击保存不会产生重复用户记录或重复上传。

## 4. 收藏、关注与历史自动同步

- [ ] 测试账号 A 在设备 1 收藏一件作品后，设备 2 自动出现该收藏。
- [ ] 测试账号 A 在设备 1 关注一位画家后，设备 2 自动出现该关注。
- [ ] 测试账号 A 的浏览历史在设备间按最近时间合并。
- [ ] 断网新增收藏后恢复网络，数据能够自动重试上传。
- [ ] 重复同步不会产生重复收藏、重复关注或虚增浏览次数。
- [ ] 测试账号 B 无法看到测试账号 A 的任何个人数据。

## 5. 隐私与账号数据管理

- [ ] “隐私与授权”页面可以打开微信官方隐私保护指引。
- [ ] 页面准确说明头像昵称、收藏关注、历史和下载的数据用途及保存位置。
- [ ] 清除本机浏览历史不会删除云端、其他设备、下载记录或系统相册图片。
- [ ] 清除本机个人数据不会删除云端、其他设备、下载记录或系统相册图片。
- [ ] 所有清除操作均有二次确认、等待态、成功反馈和失败恢复。
- [ ] 仅使用专门测试账号执行注销。
- [ ] 注销后云端头像昵称、收藏、关注和历史均不可读取。
- [ ] 注销失败时本机数据不会被提前清除，再次操作可以继续完成。

## 6. 帮助、反馈与关于页面

- [ ] “帮助与反馈”可以正常进入，FAQ 每次只展开一项。
- [ ] 真机点击“联系人工客服”可以进入微信客服会话。
- [ ] 已绑定客服人员能够收到测试账号发送的文字和截图并完成回复。
- [ ] 客服页面明确提示不要发送无关敏感信息。
- [ ] “关于 Masterpiece”显示产品名称、版本、产品定位和三个产品原则。
- [ ] 关于页面可以跳转到“内容与权利说明”“隐私与授权”和“帮助与反馈”。
- [ ] “内容与权利说明”覆盖资料形成、准确性边界、来源与权利归属、免责声明和纠错反馈。
- [ ] 免责声明明确内容不构成鉴定、真伪判断、估值、交易、投资、法律或其他专业建议。
- [ ] “内容与权利说明”可以正常跳转到“帮助与反馈”。

## 7. 性能与稳定性

- [ ] 五分钟内重复进入“我的”页不会重复调用账号云函数。
- [ ] 五分钟内重复进入“账号与数据”页不会强制刷新账号云函数。
- [ ] 页面卸载后，较晚返回的账号请求不会覆盖新页面状态。
- [ ] 网络恢复不会注册多个重复监听器或同时发起无限同步。
- [ ] 账号相关页面无明显横向滚动、按钮遮挡或安全区覆盖。
- [ ] 375px 等效宽度及 iPad 宽屏下排版均正常。

## 8. 发布门禁

- [ ] 账号专项自动化测试全部通过。
- [ ] 小程序全量自动化回归全部通过。
- [ ] 微信开发者工具编译无 Error。
- [ ] iOS 真机清单全部通过。
- [ ] Android 真机清单全部通过。
- [ ] 体验环境验证结果已记录。
- [ ] 生产环境预览结果已记录。
- [ ] 正式发布前再次确认隐私指引、客服人员和注销测试账号均已准备。
